# Radiocomunicaciones y fraseología · Veyra Classes

Fuente recibida el 06/10/2026:
- `comunicaciones.html` — clase interactiva con audio embebido.

## Integración realizada
- Nombre publicado: **Radiocomunicaciones y fraseología**.
- Ruta: `/classes/radiocomunicaciones/`.
- Se conserva la arquitectura y contenido suministrados: 7 bloques académicos + bienvenida/resultado, 36 pasos totales, 6 instrumentos y 12 comprobaciones.
- Progreso local: `localStorage` clave `veyra-com`.
- 74 clips de audio ATC/piloto permanecen incrustados en la clase.
- Se añadieron enlaces de retorno a Classes y Training Center.
- Se corrigió únicamente la discrepancia interna de la portada que decía “13 comprobaciones” cuando el recorrido contiene 12.
- Se añadió una nota visible de alcance formativo.

## Optimización de audio
El archivo original contenía aproximadamente 10,4 MB de MP3 embebido (unos 14 MB de HTML). Para poder publicarlo de forma estable en GitHub Pages sin perder la función de audio, los 74 clips fueron recodificados como MP3 mono de voz a 16 kHz / bitrate bajo para web. Los IDs, la secuencia y la lógica de reproducción no cambiaron. El HTML publicado queda en ~1,6 MB.

## Contenido
La clase mantiene, tal como fue entregada:
- técnica de transmisión y pronunciación;
- ROGER / WILCO / AFFIRM;
- readback y autorizaciones condicionales;
- fraseología por fase de vuelo;
- HF, SELCAL y CPDLC;
- MAYDAY / PAN PAN, TCAS y falla de comunicaciones;
- situaciones tipo examen;
- audio de ATC y piloto.

## Alcance
Esta publicación preserva el material suministrado; no constituye una validación normativa externa del contenido. La nota visible de la clase recuerda que, para una operación real, prevalecen la publicación aeronáutica vigente, las instrucciones ATC y los procedimientos aprobados del operador.
