# Meteorología aeronáutica · Veyra Classes

Fuente recibida: clase interactiva HTML + README del 30/09/2026.

## Estructura preservada
- Modelo pedagógico: ver → aplicar → comprobar.
- 8 bloques académicos, 33 pasos, 5 instrumentos y 15 comprobaciones.
- Misión transversal Cali → Bogotá con datos de entrenamiento.
- Progreso local: `localStorage` clave `veyra-met`.

## Revisión antes de publicar
Se mantuvo la arquitectura y el contenido base, pero se hicieron ajustes de precisión en frases operacionales que podían leerse como reglas universales. La revisión externa se contrastó con FAA-H-8083-28B Aviation Weather Handbook (2026), FAA AIM y FAA Tips on Mountain Flying.

Ajustes principales:
- Tormentas: la guía de separación de 20 NM queda acotada a tormentas severas/eco intenso y se elimina la recomendación universal de «rodear por barlovento».
- Engelamiento: clear/rime se presentan como condiciones favorecidas, no como cajas rígidas de temperatura; se elimina -40 °C como frontera operacional absoluta.
- Windshear/microburst: se remite al procedimiento publicado de la aeronave/operador en vez de prescribir «TOGA» como maniobra universal.
- METAR/TAF y mínimos: los ejemplos quedan explícitamente identificados como didácticos; mínimos, ventanas y tratamiento de BECMG/TEMPO/PROB dependen del marco y del Manual de Operaciones.
- Todos los METAR/TAF usados en la misión son datos de entrenamiento, no meteorología actual.

Esta clase es formativa. No sustituye documentación meteorológica vigente, cartas, SOP/OM ni criterios de despacho del operador.
