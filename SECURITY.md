# Política de seguridad

## Reporte responsable

Si identifica una vulnerabilidad en Veyra Pilot Intelligence, repórtela de
forma privada a **veyrapilotintelligence@gmail.com**. Incluya una descripción
clara, el componente afectado, pasos mínimos de reproducción y el impacto
observado.

No publique vulnerabilidades, credenciales, datos personales, información
académica u operativa en incidencias, discusiones o repositorios públicos.

## Alcance y autorización

El acceso al sitio o al código no autoriza pruebas intrusivas. No realice
acciones que alteren datos, afecten la disponibilidad, eludan controles de
acceso, accedan a cuentas ajenas o comprometan información de estudiantes,
instructores u organizaciones. Cualquier prueba debe contar con autorización
previa y escrita.

El envío de un reporte no crea por sí solo un programa de recompensas ni una
relación contractual. Se procurará acusar recibo y coordinar una divulgación
responsable cuando corresponda.
