Doors, Exits & Windows

Una abertura en el fuselaje no es simplemente una puerta. Es estructura, presurización, evacuación, hidráulica y disciplina operacional. En esta clase, el riesgo más importante no es memorizar componentes: es saber qué estado tiene cada abertura y qué ocurrirá si alguien la opera.

Pressure helps keep the door closed.

Human factors: Airbus slide arming/disarming SOPs use command → action → confirmation, and operators may use the PIN-LEVER-PIN mental model.

INADVERTENT SLIDE DEPLOYMENT

Opening an armed door from inside during normal ground operations can deploy the slide, injure personnel and seriously disrupt the operation.

EVACUATION WITH SLIDE DISARMED

An emergency exit opened from inside without its slide armed may leave the intended evacuation aid unavailable. This is why arming discipline and cross-check matter.

04 · TURNAROUND SEQUENCE

The door state changes with the phase.

Recorre un ciclo completo de vuelo. El objetivo no es memorizar una frase: es saber qué estado debe tener la puerta antes de que alguien la opere.

Operator SOP governs the exact callouts and responsibilities. The stable concept is command → arm/disarm action → cross-check / confirmation before door operation.

08 · WINDOWS

Visibility is only one function.

Las cockpit side windows pueden convertirse en una vía de escape. Las passenger windows son estructuras multicapa que administran presión, redundancia y condensación.

COCKPIT SIDE WINDOW
FUNCTION

SLIDING EMERGENCY ESCAPE

The sliding cockpit side window can be used as a flight-crew emergency exit with the installed escape rope / escape means.

Passenger-window precision: teach the assembly as multi-pane. A small breather/bleed feature manages pressure between panes and condensation; exact pane load-sharing belongs to the applicable structural documentation.
09 · FAILURE REASONING

What capability is actually lost?

Una alerta de puerta, una discrepancia de sensor o un daño de ventana no significan lo mismo. Diagnostica por consecuencia operacional.
