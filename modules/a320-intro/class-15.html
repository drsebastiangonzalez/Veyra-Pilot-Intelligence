CLASS 15 · ATA 34 · NAVIGATION

The aircraft only flies as well as the data it trusts.

ADIRS, GPS, radioayudas, radioaltímetros, GPWS/TAWS, TCAS y weather radar forman la capa de percepción del A320. Esta clase no trata de memorizar sensores: trata de entender qué fuente alimenta qué función, cómo se detecta una discrepancia y qué hacer cuando una fuente deja de ser creíble.

SOURCE → COMPARE → VALIDATE → RECONFIGURE → FLY
01 · THE SOURCE OF TRUTH

Failure is manageable. Plausible bad data is dangerous.

Una fuente que se declara fallada puede aislarse. Una fuente que entrega un dato erróneo pero plausible puede alimentar displays, protecciones y automatismos antes de que la discrepancia sea reconocida.

THE HARD PROBLEM IS NOT “NO DATA”. IT IS “WRONG DATA THAT STILL LOOKS BELIEVABLE”.

Air Data

ADR calcula velocidad, Mach, altitud y temperatura a partir de presiones/sondas exteriores. Su debilidad: obstrucción, contaminación o medición errónea.

Inertial Data

IR entrega actitud, rumbo, aceleraciones y navegación inercial. No depende de pitot/static, pero la posición inercial acumula error con el tiempo.

Operational meaning

El avión usa múltiples fuentes, pero cada consumidor aplica su propia lógica de comparación y reconfiguración. No existe un único “votador” universal para todo ATA 34.

04 · IR ALIGNMENT LAB

Before it can navigate, it must know how Earth is moving beneath it.

La alineación establece la referencia inercial inicial. El avión debe permanecer inmóvil durante el proceso. Los tiempos exactos, limitaciones por latitud y procedimientos se verifican en FCOM.

NAV alignment: la unidad establece referencias de actitud/rumbo y navegación inercial desde una posición inicial válida.

05 · FM POSITION LAB

Position is a solution, not a single sensor.

El FM integra información inercial y, según disponibilidad/equipamiento, actualizaciones de GPS y radio. La precisión disponible es la que importa operacionalmente.

GPS PRIMARY indicates the FM has validated GPS as the primary high-accuracy position source. Loss of GPS PRIMARY does not automatically mean “navigation lost”; it means the crew must assess remaining accuracy against the operation being flown.
06 · RADIO NAVIGATION

Automatic when available. Manual when necessary.

VOR, ILS, DME, optional ADF and GPS complement the inertial solution. The FMGS normally manages radio tuning; RAD NAV allows manual selection when operationally required.

FM auto-tuning

El FM selecciona ayudas adecuadas según fase, plan y disponibilidad. El piloto normalmente supervisa más que “persigue frecuencias”.

RAD NAV

Permite forzar una sintonía manual concreta. Una entrada manual puede reemplazar temporalmente la lógica automática asociada a ese campo.

RMP backup

En configuraciones A320 que disponen de navegación de respaldo vía RMP, puede utilizarse para sintonía de radioayudas si la cadena FMGS no está disponible. La implementación depende del estándar.

08 · TERRAIN AWARENESS

Reactive protection became predictive awareness.

Classic GPWS reacts to dangerous closure/configuration patterns. Enhanced terrain-awareness functions add aircraft position plus terrain/obstacle databases to warn earlier and support terrain display on the ND.

Reactive GPWS logic

Uses radio height, vertical trend, configuration and other inputs to detect hazardous situations such as excessive descent rate, terrain closure or altitude loss after takeoff.

Enhanced / TAWS logic

Uses position and a terrain database to look ahead. The operational difference is prediction: the system can identify a threat before the aircraft is directly over it.

Remember: terrain awareness is a safety net, not a substitute for navigation, procedure compliance or stabilized-approach criteria.
09 · TCAS CONFLICT LAB

TA means prepare. RA means fly the resolution.

TCAS surveillance uses upper/lower antenna coverage and coordinates resolution logic with compatible traffic. If an RA conflicts with an ATC instruction, the RA takes priority; ATC is advised as soon as practical.

Configuration note: some A320 standards include AP/FD TCAS, which can provide FD/AP guidance to follow an RA. Crews must know whether the specific aircraft has the function available and also know the standard TCAS procedure.
10 · WEATHER RADAR LAB

Reflectivity is not the same thing as “danger”.

Weather radar primarily sees hydrometeors through radar reflectivity. Correct interpretation means understanding attenuation, gain/tilt logic and the limits of what the sensor can reveal.

PRECIPITATION REFLECTIVITY
Normal interpretation: radar reflectivity helps identify precipitation and convective structure. Avoid “painting” a cell as if the color itself were a route clearance.

Wet turbulence

Aircraft equipped with the relevant TURB function can detect turbulence associated with precipitation/hydrometeors within the function's operating envelope.

Clear-air turbulence

Not detected by conventional airborne weather radar because there may be insufficient hydrometeor reflectivity.

Predictive windshear

A distinct hazard-detection function that can warn of windshear ahead of the aircraft near the ground when installed/available.

11 · UNRELIABLE SPEED LAB

When speed becomes untrustworthy, fly attitude and thrust.

Pitot/static contamination can generate erroneous speed and/or altitude. The most dangerous moment is before the crew has positively identified that the indications are unreliable.

12 · FAILURE REASONING

Diagnose the capability, not just the component.

El objetivo es pasar de “qué caja falló” a “qué información puedo seguir creyendo, qué automatización depende de ella y qué operación sigue disponible”.

13 · SYSTEM INTERFACES

Navigation data reaches almost everything.

ATA 34 is not isolated. It feeds the systems that guide, protect, display, warn and manage the aircraft.

Flight Controls

Air-data and inertial inputs support flight-control laws and protections. Loss of reliable inputs can force reconfiguration.

Auto Flight

FM/FG depend on position, air data, attitude and radio-navigation inputs to compute and guide the flight path.

Indicating

PFD/ND display these sources; flags/comparators help the crew recognize when a parameter is unavailable or inconsistent.

Pressurization / Warnings

Static pressure, radio height and flight-phase data support other system logic, warning inhibition and automatic functions.

14 · MICROCHECK

Can you tell when the aircraft should stop trusting a source?

Diez escenarios. No basta con conocer la sigla: debes identificar qué dato está en riesgo, qué funciones dependen de él y cuál es la prioridad operacional.

VALID DATA BUILDS AUTOMATION. DOUBTFUL DATA DEMANDS PILOT JUDGMENT.
